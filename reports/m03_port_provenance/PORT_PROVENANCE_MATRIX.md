## Scope cautions

- “Thyme-based” is an image/identity lineage classification, not proof that every vendor/odm file came unchanged from OS1.0.4. The exact stock package is a comparison reference, not verified as the original porter's input.
- The package contains a working component set, but kernel compilation and individual authorship are not established by a banner alone. No item is classified CONFIRMED_COMPILED.
- Runtime success validates the complete selected bundle, not each image independently or the inferred first-stage mechanism.
- Official vbmeta rollback_index fields are image metadata, not a readout of device rollback fuses/RPMB state.
